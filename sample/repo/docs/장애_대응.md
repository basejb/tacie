# 장애가 났을 때

## 웹훅이 계속 실패할 때

1. 대시보드의 "가맹점별 실패율"에서 특정 가맹점만 실패하는지 봐요.
2. 한 가맹점만 실패하면 대개 가맹점 서버 문제예요. 재시도 3번이 모두 실패한 이벤트는 `dead_letters` 테이블로 가요. 가맹점이 복구되면 `POST /admin/dead-letters/replay?merchant=<id>`로 다시 보내요.
3. 모든 가맹점이 실패하면 우리 쪽 문제예요. Redis 연결과 최근 배포를 먼저 봐요. 최근 배포가 의심되면 [롤백](배포.md#롤백)해요.

## 알림

실패율이 5분 동안 5%를 넘으면 #paymint-alerts 채널로 알림이 가고, 당번(on-call)에게 전화가 가요. 당번 순서는 팀 캘린더에 있어요.
