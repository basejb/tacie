# 0001. 재시도 정책: 최대 3번, 0.5초부터 두 배씩

- 상태: 채택 (2025-03-12)
- 정한 사람: 결제플랫폼 팀

## 배경

가맹점 서버가 잠깐 죽었다 살아나는 경우가 많았어요. 재시도가 없을 때는 결제 완료 알림을 놓친 가맹점이 직접 문의하는 일이 주에 몇 번씩 있었어요.

## 결정

- 실패하면 최대 3번 다시 보내요(`PAYMINT_RETRY_MAX=3`).
- 간격은 0.5초에서 시작해 두 배씩 늘려요(0.5초, 1초, 2초). 지터를 ±20% 넣어서 여러 이벤트가 한꺼번에 몰리지 않게 해요.
- 3번 모두 실패하면 `dead_letters`로 보내고 사람이 다시 보내요.

## 다른 안

- 5번 재시도: 실패한 가맹점 하나 때문에 큐가 길게 밀렸어요(2025-02 장애). 그래서 줄였어요.
- 고정 간격 1초: 가맹점이 다시 살아나는 순간 요청이 몰렸어요.
