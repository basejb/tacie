# 설정 값과 환경 변수

모든 값은 환경 변수로 바꿀 수 있고, 없으면 `src/config.ts`의 기본값을 써요.

| 환경 변수 | 기본값 | 뜻 |
| --- | --- | --- |
| `PORT` | 8080 | API 서버 포트 |
| `DATABASE_URL` | (없음, 꼭 필요) | 가맹점 정보와 전송 기록을 두는 Postgres |
| `REDIS_URL` | `redis://localhost:6379` | 이벤트 큐(Redis Streams) |
| `PAYMINT_RETRY_MAX` | 3 | 가맹점 서버가 실패했을 때 다시 보내는 최대 횟수. 첫 전송은 세지 않아요 |
| `PAYMINT_RETRY_BASE_MS` | 500 | 재시도 간격의 시작 값. 0.5초, 1초, 2초처럼 두 배씩 늘어요 |
| `PAYMINT_WEBHOOK_TIMEOUT_MS` | 3000 | 가맹점 서버 응답을 기다리는 시간(3초). 넘기면 실패로 보고 재시도해요 |
| `PAYMINT_SIGNING_SECRET` | (개발용만) | 서명 비밀값의 기본값. 운영에서는 가맹점마다 DB에 있는 값을 써요 |

재시도 횟수를 3으로 정한 이유는 [결정 0001](결정/0001-재시도-정책.md)에 있어요.

## 가맹점별 설정

가맹점마다 웹훅 주소와 서명 비밀값은 `merchants` 테이블에 있어요. 관리자 API `PATCH /admin/merchants/:id`로 바꿔요.
